Topology (diagram)
Each region row has its own provider. Use this only as the default when you click + Add region. Hybrid example: SaaS row on GCP + On-Prem JPS row on Azure.
One row per location. Set Provider and Site (SaaS JPD vs On-Prem JPS) per row. A row needs at least one Primary / Additional / Edge count to appear in the diagram. Blank or non-geographic names (On-Prem DC, etc.) land in OTHER, separate from Central. Diagram groups into West | Central | East | Other.
Most customer Edge POPs are self-managed and receive Release Bundles from Primary. Use Cloud Edge only when the order is JFrog-operated Distribution Cloud Edge Nodes.
